# مدل‌ها — Models

فایل‌های `.fbx` این‌جا می‌روند. فهرست جای‌ها در `model-slots.txt` است و
راهنمای کامل در `docs/50-models.md`.

دو منو در یونیتی:

```text
Tehran Noir → مدل‌ها → درست‌کردن متریال‌ها (URP)
Tehran Noir → مدل‌ها → جایگزینی در همه‌ی صحنه‌ها
```

اجرای اول قبل از دومی؛ وگرنه مدل با متریال صورتی (Standard در URP) می‌آید.
