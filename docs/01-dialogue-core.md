# مرحله ۱ — هسته‌ی موتور دیالوگ

هدف این مرحله: فایل `.txt` دیالوگ داخل Unity خوانده شود و **بدون هیچ UI**، با همان
زمان‌بندی بازی در Console پخش شود.

## فایل‌ها

مسیر هر فایل در ریپو، همان مسیر داخل پروژه است؛ بدون تغییر کپی کن.

| فایل | کار |
| --- | --- |
| `Assets/_Project/Scripts/Dialogue/DialogueModel.cs` | ساختار داده: گره، خط، گزینه |
| `Assets/_Project/Scripts/Dialogue/DialogueCondition.cs` | خواندن و سنجش شرط‌ها |
| `Assets/_Project/Scripts/Dialogue/DialogueParser.cs` | خواندن فایل و پیدا کردن خطا |
| `Assets/_Project/Scripts/Dialogue/WorldState.cs` | متغیرهای جهان (زمان، هوا، رابطه، …) |
| `Assets/_Project/Scripts/Dialogue/DialogueRunner.cs` | اجرای دیالوگ |
| `Assets/_Project/Scripts/Dialogue/DialogueConsoleTester.cs` | تست در Console |
| `Assets/_Project/Dialogue/reza.txt` | دیالوگ نمونه |

## تنظیم دستی در Unity

1. فایل‌های `.cs` را در `Assets/_Project/Scripts/Dialogue/` بگذار.
2. `reza.txt` را در `Assets/_Project/Dialogue/` بگذار.
3. در صحنه‌ی `Sandbox` یک GameObject خالی بساز: نامش `DialogueTester`.
4. کامپوننت `DialogueConsoleTester` را به آن اضافه کن.
5. فیلد `Dialogue File` را با `reza.txt` پر کن.
6. `Play` بزن و `Space` را فشار بده.

هیچ تنظیم دیگری لازم نیست. کاراکتر، دوربین و HUD دست‌نخورده می‌مانند.

## کنترل‌ها

| کنش | کلید |
| --- | --- |
| شروع دیالوگ | `Space` |
| رفتن به خط بعد (زودتر) | `Space` یا `Enter` یا `B` گیم‌پد |
| انتخاب گزینه | کلیدهای `1` تا `9` |
| مکث هر خط | `Seconds Per Word × تعداد کلمه`، حداقل ۱٫۲ ثانیه |

## تست پذیرش

بعد از `Space` باید به‌ترتیب ببینی:

1. `شروع «reza» — 9 گره، 3 متغیر.`
2. `[reza] سلام. اولین باره می‌بینمت.` — بعد از حدود ۱٫۴ ثانیه خودش جلو می‌رود.
3. `[reza] بگو ببینم چی می‌خوای.`
4. سه گزینه با شماره.
5. با `1`: دو خط درباره‌ی دیشب، بعد `برو، کارت دارم.` و پیام پایان.

## تست شرط‌ها

در Inspector، بخش **دنیای تست**:

| `Initial Variables` | نتیجه‌ی مورد انتظار |
| --- | --- |
| `met.reza = true` | مستقیم به `greet_known`؛ چون رابطه ۰ است: «بازم تو؟ چی می‌خوای؟» |
| `met.reza = true` و `rel.reza = 30` | «سلام رفیق. بازم اومدی.» |
| `met.reza = true` و `rel.reza = 60` | «نادر جان! بفرما.» |
| `time = night` | «این وقت شب بیداری؟» |

هر خط در آرایه یک خانه است و با همان قاعده‌ی `[do]` خوانده می‌شود.
`Reset World On Start` را روشن بگذار تا هر تست از صفر شروع شود.

## عملگرهای شرط

| عملگر | معنا |
| --- | --- |
| `=` یا `==` | برابر (هر دو یکی‌اند؛ `=` تنها هم پذیرفته می‌شود) |
| `!=` | نابرابر |
| `>` `<` `>=` `<=` | مقایسه‌ی عددی |
| `and` `or` `not` | ترکیب |
| `(` `)` | گروه |

پیش از این فقط `==` پذیرفته می‌شد و `=` تنها «بخش اضافه» می‌داد؛ همان چیزی که
قاعده‌های `items.txt` را بی‌صدا حذف کرد. حالا هر دو یکی‌اند.

## خطاهای رایج

| پیام Console | معنی |
| --- | --- |
| `مقصد پیدا نشد: «x»` | جایی به گره‌ای نوشته‌شده با این نام پرش شده، ولی چنین گره‌ای نیست |
| `node «x» نه [opt]/[go]/[end] دارد` | گره بن‌بست است |
| `شرط نامعتبر: …` | اشتباه تایپی در شرط |
| `شناسه تکراری` | دو `[node]` با یک نام |

خطاها در Console با شماره‌ی خط فایل گزارش می‌شوند و دیالوگ شروع نمی‌شود.
