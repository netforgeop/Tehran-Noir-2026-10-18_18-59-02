# Dialogue Viewer

ابزار مستقل برای نوشتن، دیدن و **تست** دیالوگ‌های Tehran Noir.
به Unity، نصب یا اینترنت نیاز ندارد.

| مورد | مقدار |
| --- | --- |
| فایل | `tools/DialogueViewer.html` |
| اجرا | دوبار کلیک (Chrome / Edge / Firefox) |
| ورودی | فایل `.txt` دیالوگ |

## اجرا

1. فایل را باز کن.
2. فایل دیالوگ را روی صفحه بکش و رها کن (یا دکمه‌ی افزودن فایل).
3. تب **جزئیات**: گراف دیالوگ و جزئیات هر گره.
4. تب **دنیای تست**: مقدار متغیرهای جهان (زمان، هوا، رابطه، …).
5. تب **بررسی**: خطاها و هشدارها با شماره خط.
6. دکمه **تست**: پخش دیالوگ دقیقاً مثل داخل بازی.

## حالت تست

| کنش | کلید |
| --- | --- |
| جلو بردن دیالوگ | کلیک روی جعبه، `Space`، `Enter`، گیم‌پد `A` یا `B` |
| انتخاب گزینه | کلیک، `1`–`9`، `↑` `↓` + `Enter`، D-pad + `A` |
| بستن | `Esc` |

مکث هر خط = بیشترین مقدار بین **۱٫۲ ثانیه** و **تعداد کلمه × ۰٫۳۵ ثانیه**.
مقدار ۰٫۳۵ در همان پنجره‌ی تست قابل تغییر است.

## متغیرهای جهان

| متغیر | نوع | مقدار |
| --- | --- | --- |
| `time` | متن | `morning` / `noon` / `evening` / `night` |
| `weather` | متن | `clear` / `rain` / `fog` / `snow` |
| `energy` `fear` `trust` | عدد | ۰ تا ۱۰۰ |
| `rel.*` | عدد | رابطه‌ی نامتقارن با هر شخص |
| `met.*` `present.*` | بولی | دیده‌شده / حاضر |
| `flag.*` | عدد | پرچم‌های داستانی |

سطح رابطه از `rel.*` **محاسبه** می‌شود، ذخیره نمی‌شود:
غریبه ۰–۱۹، آشنا ۲۰–۴۹، دوست ۵۰+.

## فرمت دیالوگ (خلاصه)

| تگ | کار |
| --- | --- |
| `[person] id` | شروع فایل و شناسه‌ی گوینده |
| `[name] fa \| en` | نام، در دو زبان |
| `[role] fa \| en` | نقش، در دو زبان |
| `[cast] id` | شخص دیگری که در این دیالوگ حاضر است |
| `[node] id` | شروع یک گره |
| `[say] speaker \| fa \| en` | یک خط دیالوگ |
| `[opt] fa \| en -> target` | گزینه |
| `[go] target` | پرش |
| `[if] cond` | شرط چسبان برای خطوط بعدی |
| `[if] cond -> target` | پرش شرطی |
| `[else]` | پایان شرط چسبان |
| `[do] rel.reza +5` | تغییر مقدار جهان |
| `[end]` | پایان گره |

هر خطا و هشدار، همراه با شماره خط، در تب **بررسی** فهرست می‌شود.

## نکته مهم

شرط هر پرش (`[if] cond -> target`) **به‌تنهایی** ارزیابی می‌شود؛ یعنی علاوه بر شرط چسبان،
خودِ همان شرط هم باید درست باشد. باگ «با اینکه آشنا بودیم، باز اولین دیدار پخش شد»
از همین‌جا بود و رفع شده است.
