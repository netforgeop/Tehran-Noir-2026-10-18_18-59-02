# ۳۳. شبکه‌ی وسایل — بازطراحی بخش «وسایل»

تاریخ: ۲۰۲۶-۱۱-۱۲ — جلسه‌ی بیست‌ویکم

## ۱. چه چیزی عوض شد و چرا

| قبل | بعد | دلیل |
| --- | --- | --- |
| ردیف‌های متنی با آیکون کوچک | کارت‌های ۴×۳ با نوار رنگ دسته، آیکون و تعداد | یک آیتم در یک نگاه دیده شود |
| بدون دسته‌بندی | نوار دسته: همه / اسناد / کلیدها / بقیه | با ۲۰ آیتم، فهرست تک‌ستونی بی‌فایده می‌شود |
| بدون صفحه‌بندی | ۱۲ کارت در صفحه + `صفحه ۱ / ۲` | سقف ثابت، بدون بریدن ردیف |
| فقط کیبورد | کیبورد + ماوس (هاور/کلیک) | قاعده‌ی «هر منو با ماوس و کیبورد» |
| کد داخل تب | `CharacterItemsSection` جدا | تب ۵۰۰ خطی می‌شد |

## ۲. چیدمان (نسبت به گوشه‌ی بالا-راستِ ستون محتوا)

ستون از `x=500, y=236` پنل شروع می‌شود و عرضش ۱۲۹۰ است.

| عنصر | جایگاه |
| --- | --- |
| نوار دسته | `y=0`، ارتفاع ۴۰ |
| شبکه | `y=64`، کارت ۳۰۶×۱۴۸، فاصله ۲۲ و ۱۸ |
| خط شرح | `y=570` |

چهار ستون: `4×306 + 3×22 = 1290` (دقیقاً عرض ستون).
سه ردیف: `64 + 3×148 + 2×18 = 544`؛ شرح از ۵۷۰؛ نوار پایین از ۹۴۹ — همیشه جا هست.

در فارسی ستون‌ها از راست شروع می‌شوند، در انگلیسی از چپ؛ نوار دسته هم آینه می‌شود.

## ۳. کارت

| بخش | جزئیات |
| --- | --- |
| زمینه | گرادیان تیره + حاشیه‌ی نازک؛ کارت انتخاب‌شده حاشیه‌ی طلایی ۲ پیکسل |
| نوار دسته | ۴ پیکسل در لبه‌ی داخلی: سند استخوانی، کلید طلایی، بقیه خاکستری |
| آیکون | ۵۲ پیکسل، همان رنگ نوار |
| نام | ۲۲ پوینت، حداکثر ۲۲ کاراکتر با «…» |
| نوع | ۱۵ پوینت، کم‌رنگ |
| تعداد | ۲۶ پوینت، طلایی، `ForceFix` تا رقم فارسی درست شود |

## ۴. ناوبری

| کلید | در شبکه | روی نوار دسته |
| --- | --- | --- |
| `W` / `S` | بالا/پایین یک ردیف؛ از ردیف اول به نوار | پایین = برگشت به شبکه |
| `A` / `D` | چپ/راست با چرخش؛ عبور از صفحه | چپ/راست بین دسته‌ها و «ترتیب» |
| `Enter` | — | اعمال دسته، یا عوض کردن ترتیب |
| `Q` / `E` | بخش قبلی/بعدی تب | همان |
| ماوس | هاور انتخاب، کلیک انتخاب | هاور/کلیک دسته |

**قاعده‌ی صفحه:** اگر حرکت انتخاب را به صفحه‌ی دیگری ببرد، کارت‌های آن صفحه ساخته می‌شوند.
`S` در ردیف آخر به آیتم آخرِ صفحه‌ی بعد می‌رود (صفحه‌ی نصفه هم پوشش داده می‌شود).

## ۵. ترتیب

دکمه‌ی `ترتیب: نام / تعداد`. با عوض شدن ترتیب، **همان آیتم** زیر نشانگر می‌ماند
(انتخاب با شناسه حفظ می‌شود، نه با شماره).

## ۶. تازه‌سازی

`Inventory.Signature()` هر فریم (فقط وقتی منو باز است) با امضای هنگام ساخت مقایسه
می‌شود. اگر F10 تعدادی را عوض کند، شبکه در همان لحظه از نو ساخته می‌شود و انتخاب
تا جای ممکن سر جایش می‌ماند.

## ۷. آزمایش

| گام | انتظار |
| --- | --- |
| `Esc` → کاراکتر → `E` | جیب خالی: «جیبت خالی است» |
| پرونده را بردار → `E` | یک کارت «پرونده‌ی مهرشده» با نوار استخوانی و «۱» |
| `A` / `D` | کارت‌ها می‌چرخند؛ از آخرین کارت به اولی |
| `W` از ردیف اول | نشانگر به نوار دسته می‌رود |
| روی «اسناد» `Enter` | فقط اسناد می‌مانند |
| روی «ترتیب» `Enter` | ترتیب تعداد؛ همان آیتم انتخاب می‌ماند |
| `F10` → `item.cigarettes` = ۲۵ | کارت سیگار با «۲۰» (سقف) می‌آید |
| `F10` → `item.file.sealed` = ۰ | کارت همان لحظه می‌رود |
| کلیک روی دسته/کارت | همان کاری را می‌کند که کیبورد |
| زبان انگلیسی | چیدمان آینه، `Documents / Keys / Other` |
