# ۲۰ — کارت تعامل تازه، انتخاب با اسکرول، پرونده روی میز

## ۱. چه عوض شد

| قبل | بعد |
| --- | --- |
| فقط نزدیک‌ترین آبجکت دیده می‌شد | همه‌ی اهداف نزدیک جمع می‌شوند و با چرخ موس بینشان می‌چرخی |

## ۳. چیدمان

گوشه‌ی چپ-پایین، در واحد کانواس ۱۹۲۰×۱۰۸۰:

```text
┌──────────────────────────────────────────────┐
│  رضا   پرونده محرمانه   کمد            ← نوار اهداف (۳۴)
└──────────────────────────────────────────────┘
┌──────────────────────────────────────────────┐  ← ۲ پیکسل خط تاکید
│ ┌────┐  برداشتن                              │
│ │ E  │  پرونده محرمانه                       │  ۱۲۴
│ └────┘  مهر و موم‌شده                        │
│         چرخ موس: هدف بعدی                    │
└──────────────────────────────────────────────┘
```

نوار فقط وقتی ساخته می‌شود که بیش از یک هدف باشد. دایره‌ی وضعیت (سلامت/انرژی/زره و شرافت/جذبه/شهرت) مرحله‌ی بعد روی سمت راست می‌نشیند؛ این کارت از اول چپ است تا جای آن خالی بماند.

در حالت فارسی، بج کلید سمت راست و متن‌ها راست‌چین می‌شوند.

## ۵. تنظیم در Unity

**۱. رضا**

`Reza` را انتخاب کن → بخش `Identity`:

- `Display Name`: `رضا|Reza`
- `Subtype`: `همکار دفتر|Office colleague`

دو فیلد قدیمی (`Display Name` و `Role` داخل `Talk Interactable`) حذف شده‌اند؛ مقدارها را دوباره این‌جا وارد کن.

**۲. HUD**

`HUD` را انتخاب کن → `Interaction HUD`:

- `Font`: `Vazirmatn-Regular SDF`
- `Latin Font`: `RobotoCondensed-Bold SDF`
- `Clear Existing Children`: تیک بماند — کارت قدیمی خودش پاک می‌شود
- `Sensor` و `Input`: اگر خالی‌اند خودش پیدا می‌کند

**۳. پرونده**

پوشه‌ی `Art/Office` → متریال تازه `M_Paper` با رنگ `#D9D2C2`.

زیر `Office` → `3D Object > Cube`، اسمش `File`:

| فیلد | مقدار |
| --- | --- |
| Position | `2.2, 0.78, 2.6` |
| Scale | `0.4, 0.03, 0.3` |
| Material | `M_Paper` |

کامپوننت `Pickup Interactable` را اضافه کن:

| فیلد | مقدار |
| --- | --- |
| Display Name | `پرونده محرمانه\|Confidential file` |
| Subtype | `مهر و موم‌شده\|Sealed` |
| Max Distance | `2.5` |
| Require Variable | `flag.quest.file` |
| Require Value | `1` |
| Taken Variable | `flag.file.taken` |
| Set On Take Variable | خالی |

یعنی تا وقتی رضا کار را نداده، پرونده روی میز دیده نمی‌شود.

**۴. سنسور**

روی `Player` → `Interaction Sensor`: `Search Radius` را `4` بگذار؛ `Scroll Selects` تیک بماند.

## ۶. آزمایش

۱. `Play` → قبل از حرف زدن با رضا، پرونده روی میز نیست.
۲. با رضا حرف بزن، «می‌برمش» → پرونده ظاهر می‌شود.
۳. نزدیک میز برو: کارت با «برداشتن» و نام پرونده.
۴. کنار کمد و رضا بایست تا چند هدف نزدیک شوند: چرخ موس بالا/پایین بینشان می‌چرخد؛ کلید `1`..`4` مستقیم انتخاب می‌کند.
۵. `E` → پرونده ناپدید می‌شود و `flag.file.taken` روشن می‌شود.
۶. دوباره با رضا حرف بزن: «بایگانی، انتهای راهرو».
۷. زبان را در تنظیمات عوض کن: متن دکمه (`Take` / `برداشتن`) و نام‌ها هر دو عوض می‌شوند.

## ۷. آنچه هنوز نیست

- **دایره‌ی وضعیت** (سلامت، انرژی، زره) و **شرافت، جذبه، شهرت**: مرحله‌ی بعد. سه نوار اول به آمار واقعی بازیکن نیاز دارند؛ آن‌ها را با همین مأموریت می‌سازیم تا نوار از اول به چیزی وصل باشد، نه به عدد ثابت.
- **باز کردن پرونده**: `Open`/`Read` هنوز روی پرونده نیست؛ قدم بعد از دایره، یا همراه با آن.
- **چند کار برای یک آبجکت** (Talk / Arrest / Search / …): ساختار فعلی برای هر آبجکت یک کار دارد. برای چند کار باید فهرست کارها به `Interactable` اضافه شود — تغییر کوچکی است ولی همین‌جا آگاهانه انجامش ندادم تا کارت اول تست شود.
