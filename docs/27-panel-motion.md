# ۲۷. حرکت پنل‌ها: ورود و خروج نرم

تاریخ: ۲۰۲۶-۱۱-۱۲ — جلسه‌ی سیزدهم

## ۱. قاعده

هر پنل HUD یک `PanelMotion` دارد. خودِ پنل هیچ `Mathf.MoveTowards` روی آلفا یا
موقعیت ندارد. این جداسازی دو فایده دارد:

| فایده | چرا |
| --- | --- |
| یک حرکت، همه‌جا | کارت تعامل، کمان و پنل‌های بعدی دقیقاً یک الگو دارند |
| تنظیم در یک جا | مدت، مقیاس، باد و جابه‌جایی فقط یک فهرست فیلد است |

## ۲. شکل حرکت

```
باز شدن:  ۰ → ۱  با EaseOutBack  →  کمی باد می‌کند، می‌نشیند
بسته شدن: ۱ → ۰  با همان منحنی →  اول کمی باد، بعد جمع می‌شود
```

همان «پاپ» فریم‌های مرجع. چون منحنی برای هر دو جهت یکی است، دو تنظیم جدا لازم نیست.

| پارامتر | پیش‌فرض کارت | پیش‌فرض کمان |
| --- | --- | --- |
| `openSeconds` | ۰٫۲۰ | ۰٫۲۲ |
| `closeSeconds` | ۰٫۱۴ | ۰٫۱۶ |
| `hiddenScale` | ۰٫۹۴ | ۰٫۹۰ |
| آلفا | تا ۴۰٪ آخرِ بسته شدن روی ۱ | همان |
| `overshoot` | ۰٫۰۷ | ۰٫۰۷ |
| `slidePixels` | ۱۶ | ۲۶ |
| `slideFrom` | Right | Right |

بسته شدن سریع‌تر از باز شدن است: خروج نباید معطل بماند.

## ۳. دو لایه شفافیت در کمان

| لایه | چه کاری | چرا جدا |
| --- | --- | --- |
| `CanvasGroup` ریشه | بودن/نبودن (`PanelMotion`) | ۰ تا ۱ با حرکت |
| `CanvasGroup` بدنه | پررنگ/کم‌رنگ در بی‌حرکتی | ۰٫۴۵ تا ۱ |

اگر یکی بودند، محو شدن تدریجی، حرکت ورود را خنثی می‌کرد.

## ۴. کمان و کارت تعامل

کارت تعامل که باز می‌شود، کمان کنار می‌رود (`hideWhileCardShown`، پیش‌فرض روشن).
در Inspector کمان خاموشش کن اگر نمی‌خواهی.

## ۵. فایل‌ها

| فایل | تغییر |
| --- | --- |
| `Scripts/UI/PanelMotion.cs` | جدید — تنها منبع حرکت پنل |
| `Scripts/UI/InteractionHUD.cs` | `_alpha` و `fadeSpeed` حذف؛ `_motion` جایش |
| `Scripts/UI/StatRingHud.cs` | `PanelMotion` روی ریشه + `Body` برای کم‌رنگی |

## ۶. آزمایش

| گام | انتظار |
| --- | --- |
| `Play` | کمان با یک پاپ کوچک ظاهر می‌شود |
| نزدیک رضا شو | کارت از پایین-راست با پاپ می‌آید، کمان کنار می‌رود |
| دور شو | کارت جمع می‌شود، کمان برمی‌گردد |
| ۳٫۵ ثانیه بی‌حرکتی | کمان کم‌رنگ می‌شود، نه اینکه برود |
| `Esc` | هر دو محو می‌شوند (منوی توقف) |
