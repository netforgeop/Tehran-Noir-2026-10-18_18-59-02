# Tehran Noir

بازی مستقل کارآگاهی / جنایی / معمایی با فضای تهرانِ دهه ۱۳۵۰ خورشیدی، با الهام از
L.A. Noire، GTA 1 & 2، GTA: Chinatown Wars و The Wolf Among Us.

## مشخصات فنی

| مورد | مقدار |
| --- | --- |
| موتور | Unity 6.6 (`6000.6.5f1`) |
| قالب اولیه پروژه | Universal 3D |
| دوربین | نمای سه‌بعدی از بالا با زاویه مایل، چرخان |
| سبک بصری | Retro 3D |
| هدف | پروژه آموزشی و تدریجی (نه استاندارد AAA) |

## وضعیت فعلی

- ریپازیتوری تازه راه‌اندازی شده است.
- فایل‌های `.gitignore` و `.gitattributes` مخصوص Unity اضافه شده‌اند.
- هنوز هیچ `Assets`، `Packages` یا `ProjectSettings` در Git ثبت نشده است.

## ساختار پوشه‌ها (برنامه‌ریزی‌شده)

```
Assets/
├── _Project/
│   ├── Scenes/
│   ├── Scripts/
│   ├── Prefabs/
│   ├── Materials/
│   └── Art/
└── (پوشه‌های نمونه و پکیج‌های Unity دست‌نخورده می‌مانند)
```

پیشوند `_` باعث می‌شود پوشه پروژه ما همیشه بالای فهرست Project window بماند
و با فایل‌های خودِ Unity قاطی نشود.

## Git و Unity Hub

پروژه از طریق Unity Hub به GitHub متصل شده است.
`.gitignore` باعث می‌شود پوشه‌های سنگین و تولیدشده (`Library`, `Temp`, `Logs`, `obj`, `Build`)
هرگز آپلود نشوند؛ بنابراین حجم ریپازیتوری کوچک می‌ماند.
