# ۱۳ — تنظیمات و زبان

## زبان: یک فایل برای هر زبان

```
Assets/_Project/Resources/Localization/fa.txt
Assets/_Project/Resources/Localization/en.txt
```

هر فایل سه خط سرصفحه دارد و بقیه `key = value`:

```
@name = فارسی
@rtl = true

pause.resume = ادامه بازی
```

**افزودن زبان تازه** (مثلاً آلمانی): فایل `de.txt` را در همان پوشه بساز، `@name = Deutsch` و `@rtl = false` بنویس و کلیدها را ترجمه کن. تمام. هیچ اسکریپتی باز نمی‌شود.

**خواندن در کد:** `Loc.Get(Loc.Channel.Menu, "pause.resume")`
کلید جاافتاده باشد، `<key>` چاپ می‌شود تا سریع پیدا شود.

## کانال‌ها

| کانال | چه چیزی را عوض می‌کند | ذخیره |
| --- | --- | --- |
| `Master` | همه‌ی کانال‌ها را یک‌جا | `tehran.loc.master` |
| `Menu` | متن منوی توقف و تنظیمات | `tehran.loc.menu` |
| `Subtitles` | زبان زیرنویس دیالوگ | `tehran.loc.subtitles` |

اگر همه‌ی کانال‌ها یکی باشند، ردیف «زبان کل» همان زبان را نشان می‌دهد؛ وگرنه «ترکیبی».
برای کانال تازه (مثلاً صداگذاری): یک عضو در `Loc.Channel`، یک ذخیره در `Save`، و یک ردیف.

## تنظیمات

| بخش | ردیف‌ها | جای ذخیره |
| --- | --- | --- |
| صدا | صدای کل، موسیقی، افکت‌ها، دیالوگ | `tehran.vol.*` |
| تصویر | رزولوشن، حالت نمایش، محدودیت فریم، V-Sync | `tehran.res/mode/fps/vsync` |
| گرافیک | کیفیت کلی، بافت، آنتی‌آلیاسینگ، سایه | `tehran.quality/texture/aa/shadows` |
| زبان | زبان کل، منو، زیرنویس | `tehran.loc.*` |

همه با `GameSettings` خوانده و نوشته می‌شوند؛ هیچ کد دیگری `PlayerPrefs` را مستقیم صدا نمی‌زند.

- **صدای کل** روی `AudioListener.volume` است، پس هر صدایی را کم می‌کند.
- **موسیقی/افکت/دیالوگ** ضریب‌اند. `MenuMusic` ضریب موسیقی را خودش اعمال می‌کند؛ برای صدای تازه کامپوننت `ChannelledAudio` را روی همان آبجکت `AudioSource` بگذار.
- **محدودیت فریم** وقتی عوض شود، V-Sync خودش خاموش می‌شود؛ با V-Sync روشن، سقف فریم اعمال نمی‌شود.
- **رزولوشن** فقط از فهرست خود مانیتور انتخاب می‌شود (`Screen.resolutions`).

## آیتم‌های واقعی کلید

آیکون‌ها از پکیج خودت (`Assets/_Project/Icons`) برداشته و در
`Assets/_Project/Resources/Icons/Keys/` گذاشته شدند: Esc, Q, E, Enter, Space, Tab,
چهار جهت, F1, V, W, A, S, D.

`UiKit.KeyIcon("Esc")` فایل `T_Esc_Key_White` را می‌خواند. اگر نبود، خودکار به جعبه‌ی متنی برمی‌گردد.

## کلیدها در منوی توقف

| کلید | کار |
| --- | --- |
| `Esc` | بستن |
| `Q` / `E` | تب قبلی / بعدی |
| `Tab` | بخش بعدی در تنظیمات |
| `↑` `↓` | حرکت در فهرست |
| `←` `→` | تغییر مقدار |
| `Enter` | انتخاب |
| دسته | `Start` بستن، `LB/RB` تب، `Y` بخش، `A` انتخاب |
