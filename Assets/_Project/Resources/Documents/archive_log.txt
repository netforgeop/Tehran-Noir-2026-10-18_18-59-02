#
# تگ‌ها: template=ledger / agency / office / number / date / title / columns /
#        footnote / hand / emblem / seal
# ردیف:  [row] خانه۱؛ خانه۲؛ خانه۳ ...
#   خانه‌ها با «؛» جدا می‌شوند و هر خانه «فارسی | English» است.
#   «|» فقط برای جدا کردن دو زبان است، نه برای خانه‌ها.
# شرط:   [when] شرط        ردیف‌های بعدی فقط وقتی دیده می‌شوند که شرط برقرار باشد
#        [always]          پایان شرط
#
# ردیف نادر راد عمداً شرط دارد: تا پرونده به بایگانی نرسد، اسمی از او در دفتر نیست.
# وضعیت مهر هم همان چیزی است که نادر گفته، نه لزوماً واقعیت.
#
# چرا == و نه >= ؟ چون متغیر تعریف‌نشده در موتور شرط، با نام خودش مقایسه می‌شود.
#   flag.quest.file >= 3   با متغیر تعریف‌نشده  → مقایسه‌ی متنی «f» با «3» → درست
#   flag.quest.file == 3   با متغیر تعریف‌نشده  → نادرست
# پس برای شرط‌هایی که «هنوز هیچ‌چیز ثبت نشده» باید نادرست باشند، همیشه == بنویس.
# ------------------------------
