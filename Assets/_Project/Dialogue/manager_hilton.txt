# هسته‌ی مأموریت: هر بار که دروغ می‌گوید، یک مدرک جلوش بگذار.
#
# پرچم‌ها:
#   flag.hilton.manager.met          حرف زده‌اید
#   flag.hilton.manager.claim_alibi  ادعا: «خودش صورت‌حساب داد»

#   rel.manager                      رابطه
#
# قاعده: او با یک مدرک نمی‌شکند. با دو تا، بله. و هر بار که شکست،
# داستانش یک قدم عقب‌تر می‌رود — دقیقاً مثل بازجویی‌های پرونده‌ی رضا.
