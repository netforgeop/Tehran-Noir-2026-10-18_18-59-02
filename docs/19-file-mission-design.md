# ۱۹ — مأموریت پرونده و سیستم آبرو

## ۱. دو دفتر، نه یکی

کل طراحی روی این یک قاعده ایستاده است:

| دفتر | چه چیزی دارد | چه کسی می‌بیند |
| --- | --- | --- |
| **واقعیت** — `flag.*` | فقط چیزهایی که واقعاً اتفاق افتاده | فقط بازی |
| **باور** — `known.<شخص>.*` | چیزی که هر شخص فکر می‌کند اتفاق افتاده | دیالوگ‌ها |

دروغ یعنی این‌که این دو یکی نباشند. اگر «فهمیدن» را با یک عدد تصادفی بسازیم، بازیکن یاد می‌گیرد بازی را بخواند؛ ولی اگر هر شخص فقط باورهای خودش را داشته باشد، «بعداً می‌فهمد» و «هیچ‌وقت نمی‌فهمد» خودش از دل داده درمی‌آید، بدون خط تازه.

## ۲. پرچم‌های این مأموریت

| پرچم | مقدار |
| --- | --- |
| `flag.quest.file` | 0 نگرفته · 1 دست نادر · 2 تحویل داده |
| `flag.file.opened` | true = پرونده باز شد (مهر شکست) |
| `flag.delivery` | `personal` یا `desk` |
| `flag.claim.seal` | `opened` · `already` · `none` · `unknown` |
| `flag.lie.seal` | true = ادعایی که با واقعیت نمی‌خواند |
| `known.reza.seal` | true = رضا مهر شکسته را دیده |
| `known.reza.lie` | true = رضا فهمیده دروغ گفتی |

قاعده‌ی مهر: مهر و موم یعنی شکستنش **مدرک** می‌گذارد. همان یک مدرک، همه‌ی سه مسیر را می‌سازد.

## ۳. جدول تحویل

| کاری که می‌کنی | رضا همان لحظه | بعداً |
| --- | --- | --- |
| سالم، دستی | چیزی نمی‌گوید · `rel.reza +5` | — |
| شکسته، دستی | «چرا درش بازه؟» → سه جواب | بر اساس جواب |
| سالم، روی میز | — | — |
| شکسته، روی میز | چیزی نمی‌گوید | پرونده را برمی‌دارد، مهر را می‌بیند → `known.reza.seal` |
| شکسته + انکار | شاید باور کند، شاید نه | با شاهد بعدی گیر می‌افتد |

## ۴. دروغ چه‌وقت رو می‌شود

دروغ فقط وقتی گیر می‌افتد که **دو چیز هم‌زمان** باشد:

1. رضا مدرک داشته باشد (`known.reza.seal`)
2. حرف تو با چیزی که **خودش** می‌داند نخواند

برای همین «از قبل باز بود» جواب خطرناکی است: با مدرک نمی‌خواند، ولی رد پای متناقض می‌گذارد. اگر بعداً بگویی «من بازش نکردم» و قبلاً گفتی «از قبل باز بود»، همان تناقض کافی است. ولی «یادم نیست» تناقض نمی‌سازد — فقط `rel.reza` را کم می‌کند.

یعنی دروغ یک **بدهی** است، نه یک مجازات فوری: `flag.lie.seal = true` می‌شود و `known.reza.lie` تا وقتی شاهدی نرسد false می‌ماند.

## ۵. نوارهای آبرو

سه نوار، 0 تا 100، همه از 50 شروع می‌شوند:

| نوار | با چه بالا می‌رود | با چه پایین می‌آید |
| --- | --- | --- |
| شرافت | کار درست وقتی کسی نمی‌بیند | فریب، سوءاستفاده |
| صداقت | راست گفتن، حتی وقتی ضرر دارد | دروغِ باور‌شده |
| وفاداری | انجام دادن کارِ سپرده‌شده | رها کردن کار |

نکته‌ی مهم: این‌ها از **باور**ها حرکت می‌کنند، نه از واقعیت. دروغی که هیچ‌کس باورش نکرده، آبروی تو را خراب نمی‌کند؛ فقط خودت می‌دانی. این همان چیزی است که «از نگاه بقیه چه آدمی هستی» را معنی می‌دهد.

برچسب‌ها نوار جدا ندارند؛ از همین سه نوار حساب می‌شوند:

| برچسب | شرط |
| --- | --- |
| وفادار | وفاداری ≥ 70 و صداقت ≥ 50 |
| خیانت‌کار | وفاداری ≤ 30 |
| درستکار | شرافت ≥ 70 |
| بدنام | شرافت ≤ 30 |
| معمولی | بقیه |

`rel.reza` هم جدا می‌ماند: رابطه‌ی شخصی، نه آبروی عمومی.

## ۶. مسیر ساخت

| مرحله | چه چیزی | کد لازم |
| --- | --- | --- |
| ۱ (امروز) | آشناشدن رضا + پیشنهاد مأموریت | هیچ — فقط فایل دیالوگ |
| ۲ | پرونده روی میز: برداشتن، باز کردن، گذاشتن روی میز | یک `Interactable` تازه |
| ۳ | باورها و رویارویی: سه جواب، تناقض، فهمیدن | یک کلاس کوچک + دیالوگ |
| ۴ | نوارها + تب «پرونده‌ها» در منوی توقف | یک تب، همان `PauseTab` |

مرحله‌ی ۴ همان چیزی است که خواستی «توی پاز منو بیاید»: تب فقط از `WorldState` می‌خواند، پس هیچ‌وقت با دیالوگ ناهماهنگ نمی‌شود.

## ۷. آزمایش امروز

فایل `Assets/_Project/Dialogue/reza_office.txt` ساخته شد. در Inspector روی `Reza` → `Dialogue Starter` → `Dialogue File` همین فایل را بگذار و `Start Node Id` را خالی بگذار.

۱. `Play` → برو سراغ رضا → `E`.
۲. باید چهار پنج خط بگوید و سه انتخاب بیاید.
۳. «می‌برمش» → `flag.quest.file` می‌شود 1 و `rel.reza` پنج بالا می‌رود.
۴. دوباره سلام کن: باید بگوید «پرونده هنوز دست توئه؟».
