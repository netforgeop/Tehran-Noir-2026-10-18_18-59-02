# ۱۶ — یک صفحه‌ی تنظیمات برای دو جا

## چه چیزی عوض شد

| قبل | بعد |
| --- | --- |
| `F1` زبان منوی اصلی را عوض می‌کرد | حذف شد؛ زبان فقط از «تنظیمات» |
| «تنظیمات» در منوی اصلی فقط یک پیام بود | همان صفحه‌ی تنظیمات منوی توقف را باز می‌کند |
| صفحه‌ی تنظیمات داخل `SystemPauseTab` نوشته شده بود | در `MenuSettings` نوشته شده و از دو جا استفاده می‌شود |
| زبان منوی اصلی در یک `bool persian` بود | از `Loc.Channel.Menu` می‌آید، همان کانالی که منوی توقف |

## `MenuSettings`

یک کلاس ساده‌ی C# است، نه `MonoBehaviour`:

```csharp
MenuSettings page = new MenuSettings(parentRect, font, persian, OnBack);
page.Move(1);        // ↓
page.Step(-1);       // ←
page.Activate();     // Enter / کلیک
page.NextSection();  // Tab
page.Pointer(mouse.position.ReadValue(), clicked);
```

`parentRect` هر جا باشد، صفحه همان‌جا ساخته می‌شود؛ همین دلیل است که هم منوی توقف و هم منوی اصلی می‌توانند بسازندش.
`OnBack` وقتی صدا زده می‌شود که ردیف «بازگشت» زده شود.

## منوی اصلی

- `Esc` وقتی تنظیمات باز است، تنظیمات را می‌بندد؛ وقتی بسته است، بازی را می‌بندد.
- زبان عوض شود، منو و صفحه‌ی تنظیمات هر دو با فونت زبان تازه از نو ساخته می‌شوند.

## کلیدهای ترجمه‌ی تازه

| کلید | فارسی | انگلیسی |
| --- | --- | --- |
| `menu.title` | خانه | HOME |
| `menu.sandbox` | تست سندباکس | SANDBOX TEST |
| `menu.options` | تنظیمات | OPTIONS |
| `menu.quit` | خروج | QUIT |

## تنظیم در Unity

هیچ. فونت‌های منوی اصلی همان دو فیلد قبلی `English Fonts` و `Persian Fonts` هستند و صفحه‌ی تنظیمات از `label` همان‌ها استفاده می‌کند.

## آزمایش

۱. صحنه‌ی `MainMenu` را Play کن.
۲. پایین-راست دیگر خبری از `F1` نیست.
۳. `تنظیمات` → `Enter`: صفحه‌ی چهاربخشی باز می‌شود.
۴. بخش «زبان» → زبان منو را عوض کن: هم صفحه‌ی تنظیمات و هم منوی پشتش عوض می‌شوند.
۵. `Esc`: برمی‌گردی به منو.
۶. برو به `Sandbox`، `Esc`، تنظیمات: همان صفحه با همان زبان.
