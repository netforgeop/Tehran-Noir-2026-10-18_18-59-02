# ۲۹. تب «کاراکتر» در منوی توقف

تاریخ: ۲۰۲۶-۱۱-۱۲ — جلسه‌ی هفدهم

## ۱. تصمیم

تب آخر منوی توقف از «پرونده‌ها» به «کاراکتر» تبدیل شد (تصمیم دور ۱۳). پرونده‌ها
حالا یکی از بخش‌های همین تب است، نه یک تب جدا.

## ۲. ساختار

| بخش | منبع داده | وضعیت |
| --- | --- | --- |
| خلاصه | `CharacterStats` + `WorldClock` | ساخته شد |
| وسایل | `Inventory` (روی `WorldState`) | ساخته شد — `docs/32` |
| کارها | `QuestLog` | ساخته شد — `docs/41` |
| پرونده‌ها | `WorldState` (`flag.seen.*`) | ساخته شد — `docs/41` |

`UsesSections => true` یعنی مثل تب تنظیمات، Q/E داخل این تب بخش را عوض می‌کند
و `Tab` هم بخش بعدی را می‌آورد. Esc اول به «خلاصه» برمی‌گردد، بار دوم منو را می‌بندد.

## ۳. چیدمان (۱۹۲۰×۱۰۸۰)

| عنصر | اندازه |
| --- | --- |
| ریل بخش‌ها | x=۱۳۰، عرض ۳۰۰، از y=۱۵۰، ردیف ۴۶ + فاصله ۱۲ |
| ستون محتوا | x=۵۰۰، عرض ۱۲۹۰ |
| نشان شرافت | x=۵۰۰، y=۹۶، قطر ۹۶ |
| نام | y=۹۶، ۳۴ پوینت، طلایی |
| نقش و تاریخ | y=۱۵۶، ۱۹ پوینت، خاکستری |
| خط طلایی | y=۲۰۴، ضخامت ۲ |
| ردیف ویژگی | از y=۲۳۶، ارتفاع ۶۶، فاصله ۸، پنج ردیف |

ردیف: عدد در سمت چپ، ساعت گرد در x=۱۷۶، نام در سمت راست.
ساعت: ریل تیره‌ی کامل + کمانِ مقدار با شعاع ۱۷ و ضخامت ۳٫۵؛ پر شدن از بالا
ساعت‌گرد. زیر ۲۵ سرخ کامل، ۲۵ تا ۵۰ به استخوانی، ۵۰ تا ۱۰۰ استخوانی به سفید.
آیکون داخل هر ساعت با همان رنگ. عددها فقط عددند، پس `ForceFix` می‌خواهند
(`UiKit.ForceFixNumbers`).

## ۴. تاریخ

`WorldClock.Now` خوانده می‌شود، نه `WorldState.year`. ماه‌ها با نام شمسی
(فروردین…اسفند). عددها **ASCII** داده می‌شوند و RTLTMPro خودش رقم فارسی
می‌سازد. اگر ساعتی در صحنه نبود، «تاریخ نامشخص». خط نقش و تاریخ هر فریم
تازه می‌شود (`RefreshMeta`) تا ساعت کهنه نماند.

## ۵. دسترسی پذیری

- ریل با کلیک هم کار می‌کند (`Pointer` روی مستطیل‌ها).
- `W/S` یا فلش بالا/پایین بین ردیف‌های آمار حرکت می‌کند.
- ردیف‌ها فقط‌خواندنی‌اند؛ Enter کاری نمی‌کند.

## ۶. آزمایش

| گام | انتظار |
| --- | --- |
| `Esc` → تب «کاراکتر» | «نادر»، «کارآگاه · ۱ فروردین ۱۳۵۲ — ۰۸:۲۷» |
| پنج ویژگی | ۵۰ و استخوانی؛ نه سرخ |
| `F10` → شرافت ۱۵ → برگرد | ساعت و ستاره سرخ می‌شوند |
| ساعت را در `F10` جلو ببر | خط تاریخ بدون بستن منو عوض می‌شود |
| `Q` / `E` | بخش‌ها می‌چرخند؛ راهنمای پایین «تعویض بخش» می‌گوید |
| بخش «کارها» | فهرست کارهای باز با قدم فعلی — جزئیات در `docs/41` |
| بخش «پرونده‌ها» | کاغذهای خوانده‌شده؛ `Enter` = بازخوانی — `docs/41` |
| کلیک روی یک بخش | همان بخش باز می‌شود |
| `Esc` در بخش دوم | برگرد به خلاصه؛ `Esc` دوم منو را می‌بندد |
| زبان انگلیسی | برچسب‌ها و مقدارها چپ‌چین، تاریخ با نام ماه لاتین |

## ۷. بخش‌های کارها و پرونده‌ها (جلسه‌ی ۴۰)

دو بخش آخر دیگر پیام «مرحله‌ی بعد» ندارند. هر دو با یک کلاس ساخته می‌شوند
(`DossierSection`) و داده‌شان از `QuestLog` و `DocumentLog` می‌آید. ستون
محتوا، ردیف‌های ۷۰ واحدی و حداکثر هفت ردیف.

جزئیات کامل، از جمله مسیر نشانه‌گذاری اسناد و بازخوانی از داخل منو، در
`docs/41-case-files.md` است. نکته‌ی مربوط به همین تب: `BuildSection` حالا
برای بخش ۲ و ۳ هم شاخه دارد و دیگر به `ShowNote` نمی‌افتد، مگر برای بخش
ناشناخته (نگهبان).
