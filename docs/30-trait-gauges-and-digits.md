# ۳۰. ساعت‌های ویژگی و باگ رقم فارسی

تاریخ: ۲۰۲۶-۱۱-۱۲ — جلسه‌ی هجدهم

## ۱. باگ ۲۵۳۱

در تب کاراکتر، تاریخ «۱ فروردین ۲۵۳۱» دیده شد. داده درست بود (`1352`)؛ مشکل چیدمان رقم بود.

| مرحله | چه می‌شد |
| --- | --- |
| کد ما | `1352` → `۱۳۵۲` تبدیل می‌کرد |
| `UiKit.SetRtl` | `PreserveNumbers = true` |
| `TextUtils.IsNumber` | با `preserveNumbers` فقط رقم **ASCII** را عدد می‌شناسد |
| `LigatureFixer` | رقم فارسی را «حرف RTL» می‌بیند و برعکس می‌چیند |

نتیجه: `۱۳۵۲` → `۲۵۳۱`. عدد پول (`4,500`) سالم بود، چون ASCII مانده بود.

**رفع:** `PreserveNumbers = !farsi`. حالا عدد ASCII داده می‌شود و RTLTMPro خودش
تبدیل و جهت‌دهی را انجام می‌دهد. `HudArt.Digits` هم که دستی رقم فارسی می‌ساخت حذف شد.

**قاعده‌ی تازه:** هیچ‌جا رقم فارسی دستی نساز. عدد را ASCII بده.

## ۲. تب کاراکتر

| قبل | بعد |
| --- | --- |
| نُه ردیف عددی (پول، جان، زره، استقامت، پنج ویژگی) | فقط پنج ویژگی |
| متن ساده | پنج ساعت گرد + نشان بزرگ شرافت |

- جان، زره و استقامت از این صفحه برداشته شدند (جایشان HUD است).
- هر ردیف: ساعت ۴۶ با ریل تیره و کمان مقدار، آیکون داخلش، نام، عدد.
- کمان از بالای ساعت (۹۰ درجه) ساعت‌گرد پر می‌شود.
- رنگ: زیر ۳۰ سرخ، بعد کرم، بالای ۷۰ سفید. آیکون هم همان رنگ را می‌گیرد.
- نشان بزرگ شرافت (۹۶) در سرصفحه، با همان قاعده‌ی رنگ: امضای بازی.

## ۳. آیکون‌های امضا

| ویژگی | نشان |
| --- | --- |
| شرافت | ستاره |
| جذبه | تاج |
| شهرت | آدم‌ها |
| صداقت | سند |
| وفاداری | سپر |

همه در `HudArt` ساخته می‌شوند؛ رنگشان با `Image.color` عوض می‌شود.

## ۴. `TickValues`

`PauseTab.TickValues()` هر فریم وقتی منو باز است صدا زده می‌شود. تب کاراکتر
با آن ساعت‌ها و نشان را زنده نگه می‌دارد؛ بقیه‌ی تب‌ها کاری نمی‌کنند.

## ۵. آزمایش

| گام | انتظار |
| --- | --- |
| `Esc` → کاراکتر | تاریخ «۱ فروردین ۱۳۵۲ — ۰۸:۰۰»، نه ۲۵۳۱ |
| پنج ساعت | ۵۰ → کرم؛ با `F10` روی ۲۰ → سرخ؛ روی ۹۰ → سفید |
| نشان بالای صفحه | رنگش با شرافت عوض می‌شود |
