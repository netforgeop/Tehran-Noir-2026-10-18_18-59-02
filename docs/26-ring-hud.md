# ۲۶. کمانِ HUD: جان، زره، استقامت، ویژگی

تاریخ: ۲۰۲۶-۱۱-۱۲ — جلسه‌ی دوازدهم

## ۱. چه چیزی روی صفحه است

| کمان | رنگ | چه نشان می‌دهد |
| --- | --- | --- |
| بیرونی چپ | سرخ + آبی | جان و زره، روی **یک** کمان |
| درونی چپ | زرد / سرخ | استقامت |
| راست | رنگ ویژگی | یکی از پنج ویژگی، معمولاً شرافت |
| پشت همه | سرخِ نبض‌دار | وقتی استقامت زیر صفر است |

## ۲. جان و زره روی یک کمان

کمان بیرونی ۲۰۰ واحد است: ۱۰۰ جان + ۱۰۰ زره.

| جان | زره | کمان چقدر پر است | سرخ | آبی |
| --- | --- | --- | --- | --- |
| ۱۰۰ | ۱۰۰ | ۱۰۰٪ | ۵۰٪ | ۵۰٪ |
| ۱۰۰ | ۵۰ | ۷۵٪ | ۵۰٪ | ۲۵٪ |
| ۴۰ | ۰ | ۲۰٪ | ۲۰٪ | ۰ |

از **بالای** کمان پر می‌شود و به سمت پایین کم می‌شود؛ زره همیشه بعد از جان می‌آید.

آسیب: `CharacterStats.Damage(amount)` اول زره را می‌خورد، باقی‌مانده از جان کم می‌شود.

## ۳. استقامت

| حالت | مقدار | نمایش |
| --- | --- | --- |
| سرحال | ۱۰۰ | کمان زرد کامل |
| خسته | ۰ | کمان خالی |
| مصرف بیش از حد | ‎-۱‎ تا ‎-۱۵۰‎ | کمان سرخ که از پایین بالا می‌آید |
| روی کف | ‎-۱۵۰‎ | کمان سرخ + نبض قرمز + سنگینی |

### مصرف

| کار | هزینه |
| --- | --- |
| دویدن | ۷ در ثانیه |
| پریدن | ۱۲ |
| نشانه‌گیری | ۸ در ثانیه (وقتی سلاح اضافه شود) |
| شلیک | ۶ (وقتی سلاح اضافه شود) |

دویدن از «قصد» فهمیده می‌شود (تپ دویدن + ورودی حرکت)، نه از سرعت.
اگر از سرعت استفاده شود، وقتی خستگی سرعت را زیر آستانه می‌برد مصرف قطع می‌شود،
استقامت برمی‌گردد، سرعت بالا می‌رود و همین حلقه تا آخر بازی تکرار می‌شود.

### بازیابی

| وضعیت | نرخ |
| --- | --- |
| استقامت مثبت | ۱۰ در ثانیه |
| استقامت منفی | ۵ در ثانیه — اول بدهی، بعد شارژ |
| تأخیر شروع | ۰٫۹ ثانیه بعد از آخرین مصرف |

### اثرهای منفی

| اثر | از ۱ (سرحال) تا |
| --- | --- |
| سرعت حرکت | ۰٫۵۵ |
| ارتفاع پرش | ۰٫۶ |
| پراکندگی نشانه‌گیری | ۲٫۲ برابر |
| بازیابی جان | ۰٫۲۵ |
| ترس | تا ۶ در ثانیه بالا می‌رود |

### فرسودگی

ماندن روی ‎-۱۵۰‎ برای ۶۰ ثانیه: جان ۱٫۲ در ثانیه کم می‌شود و هر ۲٫۵ ثانیه
سنگینی ۰٫۴۵ ثانیه‌ای می‌آید (سرعت × ۰٫۱۵).

## ۴. کمان راست

پنج ویژگی: شرافت، جذبه، شهرت، صداقت، وفاداری.

- به‌طور عادی شرافت.
- هر ویژگی دیگری که ± شود، ۲۵ ثانیه جایش را می‌گیرد و بعد شرافت برمی‌گردد.
- رنگ هر ویژگی جدا است.

## ۵. چرا Graphics سفارشی

`Image` با `Fill Method = Radial360` فقط کمان کامل می‌کشد و ضخامتش از عکس می‌آید.
`ArcGraphic` مش را دستی می‌سازد: زاویه‌ی دلخواه، ضخامت پارامتری، سر گرد.
یک کمان ۲۴۰ درجه حدود ۱۰۰ رأس دارد؛ ساده‌ترین و ارزان‌ترین راه.

## ۶. فایل‌ها

## ۷. آزمایش

| گام | انتظار |
| --- | --- |
| `Play` | کمان سمت راست صفحه، کم‌رنگ |
| `F10` → تب کاراکتر → `armor` → `Shift+→` چهار بار | کمان آبی پدیدار می‌شود، کمان روشن می‌شود و بعد کم‌رنگ |
| `stat.health` را ۴۰ کن | کمان سرخ کوتاه می‌شود |
| دویدن با `Shift` (تپ) | کمان زرد کم می‌شود |
| ادامه‌ی دویدن تا صفر | کمان سرخ از پایین بالا می‌آید |
| ایستادن | اول سرخ کوتاه می‌شود، بعد زرد پر می‌شود |
| `stat.honor` را عوض کن | کمان راست رنگ عوض می‌کند و برچسب «شرافت» می‌ماند |
