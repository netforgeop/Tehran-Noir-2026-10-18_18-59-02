# مرحله ۲ — پنل دیالوگ

جعبه‌ی دیالوگ روی صفحه، گزینه‌های کلیک‌شدنی و همان مکث کلمه‌محورِ مرحله‌ی ۱.
تمام UI در کد ساخته می‌شود؛ Canvas، فونت و چیدمان دستی لازم نیست.

## فایل‌ها

| فایل | کار |
| --- | --- |
| `Assets/_Project/Scripts/Dialogue/DialogueUI.cs` | ساخت پنل، نمایش خط و گزینه‌ها، ورودی |
| `Assets/_Project/Scripts/Dialogue/DialogueTestTrigger.cs` | شروع دیالوگ از یک فایل `.txt` برای تست |

بقیه‌ی فایل‌های مرحله‌ی ۱ بدون تغییر می‌مانند.

## تنظیم دستی در Unity

1. در صحنه‌ی `Sandbox` یک GameObject خالی بساز: `DialogueSystem`.
2. دو کامپوننت به آن اضافه کن: `DialogueUI` و `DialogueTestTrigger`.
3. در `DialogueUI`:
   - `Font` → `Vazirmatn-Regular SDF`
   - `Persian` → تیک‌خورده
   - `Pause While Open` → `Size = 2`، دو خانه: `Player` و `CM_TopDown`
4. در `DialogueTestTrigger`:
   - `Dialogue File` → `reza.txt`
   - `Dialogue UI` → همان `DialogueSystem`
5. `Play` → `Space`.

`Pause While Open` اختیاری است، ولی با آن بازیکن و دوربین هنگام دیالوگ حرکت نمی‌کنند
و مکان‌نما آزاد می‌شود.

## کنترل‌ها

| کنش | کلید |
| --- | --- |
| خط بعد (زودتر) | کلیک روی جعبه، `Space`، `Enter`، `B` گیم‌پد |
| انتخاب گزینه | کلیک، `1` تا `9`، `↑↓` + `Enter`، D-pad + `A` |
| مکث هر خط | `max(1.2, تعداد کلمه × 0.35)` ثانیه |

## تست پذیرش

1. `Space` → جعبه‌ی دیالوگ پایین صفحه ظاهر می‌شود و نام «رضا» بالای آن است.
2. خط اول بعد از حدود ۱٫۴ ثانیه خودش عوض می‌شود.
3. کلیک روی جعبه، خط را فوراً جلو می‌برد.
4. در گره‌ی `ask` سه گزینه زیر متن می‌آیند؛ با کلیک یا `1` تا `3` انتخاب می‌شوند.
5. گزینه‌ی انتخاب‌شده با کلیدهای جهت، پس‌زمینه‌ی روشن‌تری می‌گیرد.
6. آخرین خط، جعبه را می‌بندد و کنترل به بازی برمی‌گردد.

## عیب‌یابی

| نشانه | علت |
| --- | --- |
| مربع یا جای خالی به‌جای حروف | فونت TMP انتخاب نشده یا فونت asset حروف فارسی ندارد |
| حروف جدا از هم (`س ل ا م`) | RTLTMPro نصب نیست؛ شکل‌دهی فارسی انجام نمی‌شود |
| `Space` کاری نمی‌کند | `DialogueFile` خالی است یا `DialogueUI` در صحنه نیست |
| مکان‌نما برنمی‌گردد | `Release Cursor While Open` را روشن کن |
| بازیکن زیر پنل حرکت می‌کند | `Player` را در `Pause While Open` بگذار |

خطاهای پارسر (مقصد ناموجود، شرط نامعتبر، …) مثل مرحله‌ی ۱ در Console با شماره‌ی خط می‌آیند
و پنل باز نمی‌شود.
