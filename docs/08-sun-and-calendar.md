# مرحله ۵ — تاریخ شمسی و خورشید واقعی

از این به بعد بازی تاریخ و ساعت واقعی دارد، و `Directional Light` از همان تاریخ
موقعیت خورشید تهران را می‌گیرد. زمستان و تابستان ارتفاع خورشیدِ ظهر با هم فرق می‌کند،
چون میل خورشید عوض می‌شود.

## فایل‌ها

| فایل | کار |
| --- | --- |
| `Scripts/World/GameDate.cs` | تاریخ شمسی + ساعت؛ جمع و تفریق روز و ماه |
| `Scripts/World/SunPosition.cs` | موقعیت خورشید (ارتفاع، آزیموت، طلوع، غروب) |
| `Scripts/World/SunDriver.cs` | چرخاندن نور و تنظیم رنگ و شدت |
| `Scripts/World/WorldClock.cs` | ساعت جهان + پرش زمانی (جایگزین نسخه‌ی قبلی) |

## تنظیم در Unity

۱. آبجکت `World` → کامپوننت `World Clock`
   - `Start Date` = سال `1352` ماه `1` روز `1` ساعت `8` دقیقه `0`
   - `Real Seconds Per Game Hour` = `25` (هر ساعت بازی ۲۵ ثانیه واقعی)

۲. همان آبجکت `World` → `Add Component` → `Sun Driver`
   - `Clock` را خالی بگذار (خودش پیدا می‌کند)
   - `Sun Light` را خالی بگذار تا از `Render Settings` بگیرد؛ اگر خالی بود،
     خودِ `Directional Light` را داخلش بکش
   - `Latitude` = `35.6892` / `Longitude` = `51.389` / `Time Zone` = `3.5` (تهران، UTC+3:30)

۳. `DialogueSystem` → `World State Provider` → `Initial Variables`:
   **هیچ خطی برای `time` و `weather` و `season` نگذار.** این‌ها را خودِ سیستم‌ها می‌نویسند.

## متغیرهای تازه برای دیالوگ

| متغیر | نوع | نمونه |
| --- | --- | --- |
| `time` | متن | `morning` / `day` / `evening` / `night` |
| `season` | متن | `spring` / `summer` / `autumn` / `winter` |
| `year` | عدد | `1352` |
| `month` | عدد | `1` تا `12` |
| `day` | عدد | `1` تا `31` |
| `hour` | عدد | `0` تا `23` |
| `weather` | متن | `clear` / `cloudy` / `rain` |
| `energy` | عدد | `0` تا `100` |

نمونه در دیالوگ:

```
[if] season == summer
[if] time == night and season == winter
[if] year >= 1354
```

## فاز روز از کجا می‌آید

`morning` و `day` و `evening` بر اساس **نسبت به طلوع و غروب واقعی** تعیین می‌شوند،
نه ساعت ثابت:

- خورشید زیر ۶- درجه → `night`
- ۰ تا ۴۰٪ روز → `morning`
- ۴۰٪ تا ۷۲٪ روز → `day`
- بقیه تا غروب (و کمی بعدش) → `evening`

برای همین در تابستان `morning` ساعت ۵ صبح شروع می‌شود و در زمستان ساعت ۷.
این عددها برای تاریخ شروع (۱۳۵۲/۰۱/۰۱) در تهران:

| | طلوع | ظهر | غروب |
| --- | --- | --- | --- |
| بهار (۱ فروردین) | ۰۶:۰۸ | ۱۲:۱۲ | ۱۸:۱۶ |
| تابستان (۱ تیر) | ۰۴:۴۸ | ۱۲:۰۵ | ۱۹:۲۳ |
| پاییز (۱ مهر) | ۰۵:۵۱ | ۱۱:۵۶ | ۱۸:۰۱ |
| زمستان (۱ دی) | ۰۷:۱۰ | ۱۲:۰۲ | ۱۶:۵۴ |

## پرش زمانی

سه تابع عمومی که کوئست‌ها و میان‌پرده‌ها صدا می‌زنند:

```csharp
WorldClock.Instance.SkipMonths(4);   // «چهار ماه بعد»
WorldClock.Instance.SkipDays(2);
WorldClock.Instance.SkipHours(9);
WorldClock.Instance.SetDate(new GameDate(1353, 7, 1, 20, 0));
```

برای تست بدون کد: روی `World Clock` → منوی ⋮ کامپوننت →
**پرش چهار ماه** / **پرش یک ماه** / **پرش یک روز**.

## شب چه می‌شود

هیچ کلید دستی‌ای نیست. وقتی خورشید زیر افق برود، همان نور به نور ماه تبدیل می‌شود:
رنگ آبی کم‌رنگ، شدت `0.10`، و از طرف مقابل آسمان. این تا مرحله‌ی آسمان و مه است؛
بعد از آن آسمان شب واقعی می‌آید.

## تست

۱. `Play` → نور باید از شرق بتابد و سایه‌ها بلند باشند.
۲. `World Clock` → **پرش چهار ماه** (از فروردین به مرداد)
   → نورش باید از بالاتر بتابد و سایه‌ها کوتاه‌تر شوند.
۳. **پرش یک روز** چند بار → ساعت جلو برود؛ در Console خط `[World]` تاریخ را نشان می‌دهد.
۴. `Real Seconds Per Game Hour` را موقتاً `2` کن تا چرخش خورشید را در چند ثانیه ببینی.
   بعدش برگردان به `25`.
۵. برای تست شب: **پرش یک ماه** تا دی، یا `Start Hour` را `20` بگذار.

## محدودیت‌های عمدی این مرحله

- آسمان و مه و محیط شب هنوز واقعی نیست؛ فقط نور خورشید/ماه کار می‌کند.
- تغییر فصل به‌صورت «کاتسین + نوشته» و کوئست‌هایی که روز را جلو می‌برند، مرحله‌ی بعد است.
