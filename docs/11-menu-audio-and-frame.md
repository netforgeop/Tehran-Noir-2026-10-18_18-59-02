# مرحله ۸ — صدای منو و کادر انتخاب به سبک Mafia

## بخش ۱ — چرا صدا پخش نمی‌شد

خودِ Console جواب داده:

```
There are no audio listeners in the scene.
```

`AudioSource` صدا را تولید می‌کند، ولی **`AudioListener`** آن را می‌شنود. هر صحنه
دقیقاً به یکی نیاز دارد و معمولاً روی `Main Camera` است. صحنه‌ی `MainMenu` را از
`Empty` ساختی، پس هیچ دوربینی نداشت؛ `MainMenuUI` موقع اجرا یک دوربین می‌ساخت
ولی رویش `AudioListener` نمی‌گذاشت. صدا پخش می‌شد و هیچ‌کس نمی‌شنید.

**رفع:** حالا `EnsureAudioListener` روی همان دوربین `AudioListener` می‌گذارد، اگر نبود.
اگر خودت دوربین داری و رویش Listener هست، دست نمی‌زند.

هیچ تنظیم دستی لازم نیست.

## بخش ۲ — کادر انتخاب

قبلاً نوار پُر بود و تمام عرض را می‌گرفت. در Mafia (image-5) کادر این‌طور است:

| گوشه | خط |
| --- | --- |
| بالا | نازک طلایی، از چپ پر و به راست محو |
| پایین | همان |
| چپ | نازک طلایی، یکدست |
| راست | **باز** — هیچ خطی نیست |
| داخل | پرکردن طلایی خیلی محو، از چپ روشن و به راست محو |

اندازه‌ها:

| مورد | مقدار |
| --- | --- |
| ضخامت خط | `2` پیکسل |
| رنگ خط | `#C7A357` با آلفای ۰.۹۵ |
| رنگ پرکردن | `#B89954` با آلفای ۰.۱۶ |
| منحنی محو | `pow(1-t, 1.8)` — یعنی نزدیک چپ تقریباً خطی، نزدیک راست خیلی نرم |
| انیمیشن | آلفا با سرعت `9` به سمت هدف (بدون پرش) |

### چطور محو می‌شود

Unity برای گرادیان، بافت می‌خواهد. یک بافت `256×1` در زمان اجرا ساخته می‌شود:
از چپ سفیدِ کامل تا راست شفاف. بعد با رنگ طلایی ضرب می‌شود. یک بار ساخته می‌شود و
برای هر سه خط و پرکردن استفاده می‌شود — بدون فایل تصویری اضافه.

### چرا سمت راست باز است

در Mafia آیتم از لبه‌ی چپ به سمت راست محو می‌شود تا چشم به سمت متن کشیده شود.
خط راست کادر را می‌بست و همان حس را از بین می‌برد.

## بخش ۳ — فایل‌ها

| فایل | تغییر |
| --- | --- |
| `Scripts/UI/MainMenuUI.cs` | `AudioListener` خودکار + کادر جدید جایگزین نوار پُر |

`MenuMusic.cs` دست نخورد.

## بخش ۴ — تنظیم در Unity

هیچ. فقط `Play`.

اگر خواستی صدا بلندتر باشد: روی `MainMenu` → `Menu Music` → `Volume`.

## بخش ۵ — آزمایش

۱. `Play` → آهنگ منو با فید ۲.۵ ثانیه شروع شود.
۲. Console نباید `There are no audio listeners` بدهد.
۳. کادر طلایی زیر آیتم اول: بالا، پایین، چپ. سمت راست باز.
۴. `↓` → کادر نرم به آیتم بعدی برود، نه پرش.
۵. با موس هاور کن → کادر همان آیتم را دنبال کند.

## بخش ۶ — اگر صدا باز هم نیامد

سه چیز را چک کن، به همین ترتیب:

1. `MainMenu` → `Menu Music` → فیلد `Clip` پر است؟
2. در Project روی `menu` کلیک کن → پایین Inspector دکمه‌ی ▶ را بزن. اگر صدا آمد،
   فایل سالم است و مشکل از صحنه است.
3. `Edit > Project Settings > Audio` → `Disable Unity Audio` تیک **نخورده** باشد.

اگر هر سه درست بود و باز هم سکوت بود، متن کامل Console را بفرست.
