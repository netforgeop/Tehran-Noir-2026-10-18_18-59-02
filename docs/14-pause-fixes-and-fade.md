# ۱۴ — اصلاح منوی توقف و محو نرم

## چه چیزی عوض شد

| مشکل | اصلاح |
| --- | --- |
| `E` می‌رفت چپ، `Q` می‌رفت راست | برعکس شد: `Q` چپ، `E` راست — همان‌جایی که بج‌ها نشسته‌اند |
| تب‌های بالا کلیک نمی‌شدند | کلیک روی هر تب همان تب را باز می‌کند؛ هاور رنگش را روشن می‌کند |
| بخش‌های «صدا/تصویر/گرافیک/زبان» کلیک نمی‌شدند | کلیک روی هر بخش آن را باز می‌کند |
| ردیف‌های تنظیمات کلیک نمی‌شدند | کلیک یا `Enter` روی هر ردیف، مقدارش را یک پله جلو می‌برد |
| فاصله‌ی نادرست بج‌ها و متن‌ها | عرض متن اندازه‌گیری می‌شود؛ فاصله‌ها دقیقاً ۱۲ پیکسل |
| باز و بسته شدن یک‌دفعه | پنل در ۰٫۱۶ ثانیه محو می‌شود و موزیک در ۰٫۸ ثانیه |
| برگشت به منوی اصلی و خروج، پرش داشتند | حالا با محو سیاه انجام می‌شوند |

کلیدهای دسته هم مثل کیبورد شدند: `LB` چپ، `RB` راست.

## پرده‌ی سیاه — `ScreenFade`

خودش ساخته می‌شود، دستی در صحنه لازم نیست. هر صحنه‌ای که لود شود، تصویر در ۰٫۶ ثانیه از سیاه روشن می‌شود.

برای محو شدن **قبل از** رفتن به صحنه:

```csharp
ScreenFade.Instance.FadeOut(0.45f, () => SceneManager.LoadScene("MainMenu"));
```

## تنظیم موزیک منوی توقف

۱. Hierarchy → `PauseMenu` → Inspector.
۲. بخش **صدا**:
   - `Music Clip` = فایل موزیک (مثلاً `menu.mp3`) را بکش داخلش.
   - `Music Volume` = 0.35 (پیش‌فرض).
   - `Music Fade Seconds` = 0.8.
۳. خالی ماندن `Music Clip` یعنی منوی توقف بی‌صدا است؛ خطایی نمی‌دهد.

موزیک از کانال «موسیقی» در تنظیمات تبعیت می‌کند، پس اسلایدر موسیقی رویش اثر دارد.

## کلیدها

| کلید | کار |
| --- | --- |
| `Esc` / `Start` | بستن |
| `Q` / `LB` | تب سمت چپ |
| `E` / `RB` | تب سمت راست |
| `Tab` / `Y` | بخش بعدی در تنظیمات |
| `↑ ↓` / `W S` | حرکت |
| `← →` / `A D` | تغییر مقدار |
| `Enter` / `A` | انتخاب؛ روی ردیف تنظیمات = یک پله جلو |
| ماوس | هاور انتخاب می‌کند، کلیک اجرا |
