# ۳۹. سه قدم دستی — تحویل پرونده

تاریخ: ۲۰۲۶-۱۱-۱۲

## ۱. چرا پیام قبلی ناخوانا شد

در پیام قبلی، نام فیلدها و نام آبجکت‌ها **داخل همان جمله‌ی فارسی** نوشته شدند.
مرورگر هنگام نمایش، خط فارسی را از راست می‌چیند و کلمه‌ی انگلیسی را از چپ؛
نتیجه این می‌شود که جمله نصف می‌شود، شماره‌ی قدم به آخر خط می‌رود و متن
«Hierarchy در پنجره‌ی .۱» دیده می‌شود. مشکل از خواندن تو نیست.

**قاعده‌ی تازه برای همه‌ی پیام‌های بعدی:**

۱. جمله‌ی فارسی هیچ حرف انگلیسی نداشته باشد.
۲. هر واژه یا مسیر انگلیسی، تنها در یک بلوک کد و در خط جدا نوشته شود.
۳. خط‌ها کوتاه باشند؛ یک کار در هر خط.
۴. جدول فقط برای مقایسه‌ی متن فارسی‌به‌فارسی. برای دستور کار، جدول نه.

قاعده در `HANDOVER.md` بخش ۱۲ هم نوشته شد.

## ۲. قدم‌ها

### قدم ۱ — شرط کار «دادن» روی رضا

**۱.** در پنجره‌ی سلسله‌مراتب، آبجکت رضا را انتخاب کن.

```text
Hierarchy → Reza
```

**۲.** در پنجره‌ی بازرس، کامپوننت گفتگو را باز کن.

```text
Inspector → Talk Interactable
```

**۳.** در آن کامپوننت، به پایین برو تا گروه تحویل را ببینی.

```text
Handover
```

**۴.** کادر شرط را پیدا کن.

```text
Handover Variable
```

**۵.** هر چه داخل کادر هست پاک کن و این خط را بنویس.

```text
item.file.sealed >= 1
```

**۶.** کادر پایین‌تر باید همین بماند؛ دست نزن.

```text
Handover Node = handover
```

**۷.** صحنه را ذخیره کن.

```text
Ctrl + S
```

نتیجه: کار «دادن» فقط وقتی روی رضا ظاهر می‌شود که پرونده واقعاً همراه بازیکن باشد.

### قدم ۲ — خانم فرهادی و بایگانی

اول ببین آبجکتی به این نام در پنجره‌ی سلسله‌مراتب هست یا نه.

```text
Farhadi
```

**اگر نیست:**

**۱.** حالت اجرا را قطع کن.

```text
Stop
```

**۲.** از نوار بالای برنامه، این منو را بزن.

```text
Tehran Noir → ساخت بایگانی و مأموریت
```

**۳.** صبر کن؛ راهرو، اتاق، دو آدم، دفتر ثبت و جعبه ساخته می‌شود و صحنه ذخیره می‌شود.

**اگر هست:** یا همان منو را دوباره بزن، یا روی خودش برو و کادر
`Handover Variable` را مثل قدم ۱ عوض کن. منو هم از این پس خودش همان شرط را می‌گذارد.

### قدم ۳ — تست خودکار

روی یک آبجکت خالی، کامپوننت تست را بگذار و اجرا کن.

```text
ItemSelfTest → Play
```

خط اول گزارش در پنجره‌ی کنسول:

```text
[Items] تست: 60 قبول، 0 رد
```

## ۳. آزمایش دستی

**۱.** کار را از رضا بگیر.

**۲.** پرونده را از میز بردار. نام کارت:

```text
پرونده‌ی مهرشده
```

**۳.** کلید خروج را بزن تا منو باز شود.

```text
Esc → تب وسایل
```

**۴.** کلید یک را بزن تا مهر باز شود. نام کارت عوض می‌شود.

```text
1
```

**۵.** کلید دو را بزن تا بخوانی.

```text
2
```

**۶.** برگرد پیش رضا. کنار «صحبت» باید کار «دادن» آمده باشد. بزنش.

**۷.** رضا می‌گوید مهر شکسته است. یکی از چهار جواب را انتخاب کن.

**۸.** کلید میان‌بر پنل تست را بزن و عدد پرونده را ببین.

```text
F10
```

باید صفر باشد:

```text
item.file.sealed = 0
```

## ۴. اگر کار نکرد

| چه دیدی | یعنی چه |
| --- | --- |
| کار «دادن» نیامد | قدم ۱ ذخیره نشده؛ فیلد را دوباره چک کن و صحنه را ذخیره کن |
| عدد صفر نشد | دیالوگ تحویل اجرا نشده؛ یک بار دیگر با رضا حرف بزن |
| خطای قرمز در کنسول | متن خطا را بفرست؛ کد را همان‌جا می‌خوانم |
| متن این سند هم به‌هم‌ریخته بود | بگو؛ شکل تازه‌ای برای نوشتن پیدا می‌کنم |

## ۵. دفتر ثبت — از دیالوگ به سند

اول حالت اجرا را قطع کن.

```text
Stop
```

از نوار بالای برنامه این منو را بزن.

```text
Tehran Noir → اتصال دفتر ثبت به سند
```

در پنجره‌ی کنسول باید این خط را ببینی.

```text
[Archive] دفتر ثبت حالا سند است: Documents/archive_log — صحنه ذخیره شد.
```

حالا وقت اجرا، دفتر روی پیشخوان یک برگه‌ی جدول‌دار باز می‌کند، نه نوار دیالوگ.

تست سند، در یک صحنه‌ی خالی:

```text
DocumentSelfTest → Play
```

انتظار:

```text
[Documents] تست: 16 قبول، 0 رد
```

## ۶. یادداشت — همان کار، یک منو

حالت اجرا را قطع کن.

```text
Stop
```

این منو را بزن.

```text
Tehran Noir → اتصال یادداشت به سند
```

در کنسول باید این خط را ببینی.

```text
[Archive] «Note» حالا سند است: Documents/note_yazdani — صحنه ذخیره شد.
```
